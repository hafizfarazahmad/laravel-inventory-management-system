# Laravel Inventory Management System

A professional Inventory Management System built with Laravel, AdminLTE, Bootstrap 5, and MySQL.

## Features

- Authentication (Laravel Breeze)
- Categories Management
- Products Management
- Suppliers Management
- Customers Management
- Purchase Management
- Sales Management
- Inventory Tracking
- Reports
- User Management

## Tech Stack

- Laravel 8
- PHP
- MySQL
- Bootstrap 5
- AdminLTE 4
- Git & GitHub
